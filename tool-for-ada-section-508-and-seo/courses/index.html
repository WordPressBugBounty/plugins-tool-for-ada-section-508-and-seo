Web Accessibility & WCAG 2.2 Compliance for Agencies

Course Objective: Equip agency teams with the knowledge and tools to integrate accessibility best practices into their workflows, ensuring WCAG 2.2 Level A and AA compliance across client projects.

Module 1: Foundations of Web Accessibility

  • What is digital accessibility and why it matters
  • Overview of disabilities and assistive technologies
  • Legal and business drivers (ADA, Section 508, AODA, etc.)
  • Introduction to WCAG 2.2 principles (POUR)

Module 2: WCAG 2.2 Deep Dive

  • Structure of WCAG: Guidelines, Success Criteria, Levels
  • Key updates in WCAG 2.2
  • High-impact criteria for agencies (e.g., 1.4.3, 2.4.3, 2.5.8)

Module 3: Accessibility in Design

  • Color contrast, typography, and visual hierarchy
  • Accessible navigation and layout patterns
  • Designing for keyboard and screen reader users
  • Tools for accessible design review

Module 4: Accessibility in Development

  • Semantic HTML and ARIA basics
  • Keyboard navigation and focus management
  • Forms, labels, and error handling
  • Common pitfalls and how to fix them

Module 5: Testing & Remediation

  • Manual vs. automated testing (Axe, WAVE, Lighthouse)
  • Screen reader basics (NVDA, VoiceOver)
  • Creating accessibility reports and remediation plans
  • Integrating accessibility into QA workflows

Module 6: Agency Implementation

  • Building accessibility into project timelines and scopes
  • Communicating accessibility to clients
  • Creating VPATs and documentation
  • Accessibility roles and responsibilities across teams
