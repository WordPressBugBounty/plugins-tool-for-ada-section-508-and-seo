Our Web Accessibility Testing Process:

  • Run a full accessibility test on every page using multiple software programs designed specifically for WCAG 2.1/2.2 and Section 508 compliance.
  • Run a manual accessibility test on every web page using our 20-step process utilizing a keyboard and multiple screen readers to help test.
  • Go through every WCAG 2.1/2.2 (A, AA) guideline to determine if your site complies with all web accessibility guidelines.
  • We complete Steps 1-3 in both desktop and mobile mode.
  • Add all the information into an easy-to-understand audit that includes our suggestions on how to fix the issues.
  • Include a 1-hour meeting to answer questions about the non-compliance issues included in the report.
